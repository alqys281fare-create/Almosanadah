# Madani font (Arabic)

Put your licensed Madani font files here with exactly these names:

- Madani-Regular.woff2  (or .ttf)
- Madani-Medium.woff2   (or .ttf)
- Madani-Bold.woff2     (or .ttf)

global.css already has the @font-face rules pointing to /fonts/...
Poppins (English) is loaded from Google Fonts in index.html.
